English Secret 📚✨

Learn English. Test Yourself. Improve Every Day!

English Secret is a learning platform designed to help students improve their English grammar, vocabulary, and test-taking skills.

🌟 Features

- 📝 Interactive English tests
- ✅ Automatic answer checking and scoring
- 📚 English learning materials by grade and topic
- 👩‍🏫 Teacher panel for managing educational content
- 🎯 Practice tests for different student levels
- 📊 Student results and progress tracking

🎓 Who Is It For?

English Secret is designed for students learning English and teachers who want to make learning more interactive.

🛠️ Technologies

- HTML
- CSS
- JavaScript
- GitHub Pages
- Supabase

🚀 Project Goal

Our goal is to build a free and accessible English learning platform where students can practise, learn, and track their progress.

📌 Project Status

The website is under development. New features are being added step by step.
